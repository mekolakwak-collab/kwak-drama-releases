# KWAK Studio

Локальна програма для створення відеоісторій.

**[Завантажити останню версію для Mac або Windows](https://github.com/mekolakwak-collab/kwak-drama-releases/releases/latest)**

Встанови програму один раз. Наступні оновлення з’являються у студії: натисни **Оновити**.

Інструкція встановлення є у кожному випуску (файл `POCHNY-TUT.md`). Mac: macOS 13+, Intel або Apple Silicon. Windows: 10/11 x64.

Оновлення перевіряються цифровим підписом KWAK. Apple Developer ID/нотаризації та Windows Authenticode у поточного випуску поки немає, тому перший запуск може показати системне попередження.

Цей репозиторій містить лише встановлювачі та підписані файли оновлень. Особисті проєкти й ключі сервісів зберігаються на комп’ютерах користувачів.
